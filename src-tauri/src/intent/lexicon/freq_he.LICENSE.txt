freq_he.tsv: Hebrew word frequencies

This file is derived from wordfreq 3.2.0 by Robyn Speer
(https://github.com/rspeer/wordfreq, data file wordfreq/data/large_he.msgpack.gz, commit 912caf6).
Changes: only words made of Hebrew letters (two or more) are kept, the 50,000 most frequent of
the list; frequencies are given as Zipf x 100, rounded.

The wordfreq Hebrew data was built from these sources, credited as wordfreq's NOTICE asks:
- Wikipedia, the free encyclopedia (http://www.wikipedia.org), CC BY-SA
- OPUS OpenSubtitles 2018 (http://opus.nlpl.eu/OpenSubtitles.php), from the OpenSubtitles
  project (http://www.opensubtitles.org/)
- Google Books Ngrams (http://books.google.com/ngrams)
- OSCAR web corpus
- word counts from the Twitter streaming API (no Twitter content is included)
